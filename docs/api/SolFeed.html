Bring a source anchor into view within its scrollable column. showInPane()

Show an article in the inline reading pane. The pane only carries the article's URL on data-article-url; a desktop host (dk/Electron) reads that and paints a native view that loads the live page — running its own JS, so a Cloudflare/JS check clears, which the old script-stripping proxy iframe could not. Reached only in inline-reader mode; on the plain web _readerInline() is false and the pop-out window is used, because a browser refuses to frame most cross-origin articles.
