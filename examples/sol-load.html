sol-load: ci-free bootstrap

This page loads sol-weather and sol-time with a single classic <script> tag — no component-interop, no hand-written import map. The tag's data-components attribute declares exactly what is loaded.

Late loading

Components can also be loaded programmatically after boot: window.solLoad('sol-calendar') returns the import promise. window.solLoadReady resolves when everything named in data-components has registered.
